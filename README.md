# 🛸 Rick and Morty React App

Welcome to the Rick and Morty React App! This project showcases characters from the Rick and Morty universe using the Rick and Morty API. The application utilizes various modern React features and libraries to enhance the user experience.

## 🚀 Features

- **Custom Hooks**: Efficient state and effect management with custom hooks.
- **API Integration**: Fetch data from the Rick and Morty API.
- **Translation APIs**: Implement multiple language support using translation APIs.
- **Styled Components**: Style components with ease using the styled-components library.
- **Bootstrap**: Responsive design with Bootstrap.
- **Local Translation**: Support for multiple languages through local translation files.

## 🛠 Technologies Used

- **React**: JavaScript library for building user interfaces.
- **Custom Hooks**: Reusable logic for managing state and effects.
- **Styled Components**: CSS-in-JS library for styling React components.
- **Bootstrap**: CSS framework for responsive design.
- **Translation APIs**: Implement language translations.
- **MovieDB APIs**: More context for the episodes.
- **Local Translation**: Manage translations with local JSON files.
- **Axios**: Axios is a promise-based HTTP Client for node.js and the browser.
- **Skeleton**: Css skeleton to charge the card.

## 📦 Installation

Clone the repository:
   
 ```bash
   git clone https://github.com/dnsue01/RickAndMortyReact.git
   cd RickAndMortyReact
   npm install
  ``` 
## 🚀 Usage

Open your browser and go to http://localhost:3000 to view the app.
